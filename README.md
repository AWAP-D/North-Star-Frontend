# North Star

North Star is a web application developed as part of OAMK's Advanced Web Applications Project (ID00CS47-3007). The project focuses on building a full-stack application using modern web technologies and collaborative development practices.

## Tech Stack

| Layer      | Technology        |
| ---------- | ----------------- |
| Frontend   | React, TypeScript |
| Backend    | Node.js, Express  |
| Database   | PostgreSQL        |
| Deployment | Microsoft Azure   |

## Project Structure

The project follows a feature-based architecture, organizing related functionality into independent modules.

The initial repository contains:

- `README.md` - Project overview and documentation.
- `CONTRIBUTING.md` - Contribution guidelines and coding standards.
- `.gitignore` - Files and directories excluded from version control.

The frontend, backend, and database structure will be expanded as development begins.

## Development Workflow

Development is managed through Git and GitHub using feature branches and pull requests.

All contributors should follow the branch naming conventions, coding standards, and commit message guidelines described in [CONTRIBUTING.md](CONTRIBUTING.md).

## Project Status

**Status:** Initial setup

The repository and contribution guidelines have been established. Application development will begin once the functional requirements are finalized.
